# Inkspire Backend Planning


## Project Overview
Inkspire backend for an art platform.

## Current Status
- Basic endpoints for authentication, art creation, theme management, and gallery are implemented.
- Testing is ongoing for all major features and endpoints.
- The project structure is modular, with controllers, models, middlewares, and utility functions.
- Docker support is included for easy deployment.
